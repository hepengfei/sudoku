# 数独本需求总览

本目录是当前产品需求与验收标准的权威来源。实现、测试和其他说明文档与本目录冲突时，以本目录为准。

## 页面需求索引

- [数独页](./sudoku-page.md)：做题界面、棋盘、输入、提交、计时和提示行为。
- [题库页](./puzzle-library-page.md)：难度目录、统计、题目状态、分页和返回定位。
- [成长页](./growth-page.md)：成长称号、练习进度、解题表现、徽章和下一步挑战。

## 产品目标

提供一本适配桌面、iPad 和手机浏览器的响应式 Web 数独本。用户可以从明确的题库目录选题，在当前设备上持续保存进度、完成记录和最佳成绩。

产品整体应保持“纸质数独书、进度可见”的体验：题库负责翻阅和回顾，数独页专注
做题，成长页呈现基于真实完成记录的个人进步；不加入游戏化积分、竞争或会暴露
答案的辅助功能。

## 全局需求

### GLOBAL-001 标准数独

- 使用标准 9×9 数独规则，单元格为空或填写 1–9。
- 每行、每列和每个 3×3 宫内不得出现重复数字。
- 题目给定数字不可修改。
- 内置题目必须格式正确、答案匹配且具有唯一解。

### GLOBAL-002 本地单人使用

- 不提供账号、云端同步、排行榜、积分、广告或多人功能。
- 进度、统计、完成历史和操作学习状态只保存在当前浏览器的 `localStorage`。
- 页面运行和做题不依赖后端服务。
- 刷新页面或关闭后重新打开时，已经保存的题目状态和统计仍可恢复。

### GLOBAL-003 题目范围与来源

- 提供入门、简单、中等、困难、地狱五个难度，每档 1000 题，共 5000 题。
- 五档题目分别存放为静态模块，只在用户打开相应难度时加载，并允许浏览器缓存。
- 题目来自公有领域的 Sudoku Exchange Puzzle Bank；入门从 Easy 中按给定数阈值拆分，各档按给定数降序和来源哈希升序确定性选择，并由本项目求解器重新验证唯一解。
- 来源版本、校验和、选择规则和复现方式以 [`docs/knowledge/sudoku-exchange-import.md`](../docs/knowledge/sudoku-exchange-import.md) 为准。
- 上游许可文本随仓库保存；无法通过格式、答案和唯一解验证的题目不得进入发布题库。

### GLOBAL-004 本地数据兼容

- 每道题的进行中状态和完成统计必须相互独立。
- 自动保存的数据至少包括棋盘填写、候选数字、累计用时、判错次数和操作提示次数。
- 完成统计至少包括正确挑战次数、最佳用时及该最佳用时的完成日期时间。
- 判错次数只在用户确认提交错误答案后增加；正确挑战次数只在用户正确完成整题后增加，两者不得混用。
- 最近完成历史最多保留 100 条。
- 已有 v1 单题进度与完成历史应一次性迁移，损坏或无法识别的数据应安全回退，不能阻止应用启动。

### GLOBAL-005 响应式与滚动边界

- 桌面、iPad 和手机均可完成选题、做题、提交和返回题库的完整流程。
- 页面只能在真实内容范围内滚动，到达内容底部后不得继续拉出一页或多页空白。
- 不得产生非预期的横向滚动条。

### GLOBAL-006 视觉与信息层级

- 题库页、数独页、棋盘、信息条、按钮和确认层统一采用纸张与棋盘格视觉语言。
- 页面第一层只保留应用/页面标题和必要导航，第二层显示当前页面最重要的信息，做题区不额外堆叠统计说明。
- 临时反馈复用既有信息区域，不通过新增固定空白区改变页面高度。

### GLOBAL-007 无解题辅助

- 不提供提示、自动填数、答案揭示、冲突高亮或输入时即时校验。
- 用户填写过程中允许暂时存在冲突，只有主动提交时检查完整答案。
- 提交错误时只告知整体不正确，不标记具体错误单元格。

## 页面流转

1. 应用打开后进入[题库页](./puzzle-library-page.md)。
2. 用户可以在题库页和[成长页](./growth-page.md)之间切换。
3. 用户从题库或成长页选择题目后进入[数独页](./sudoku-page.md)。
4. 进行中题目恢复上次保存状态；已完成题目允许再次挑战。
5. 从数独页返回时回到发起挑战前的页面；返回题库时恢复当前难度、当前题所在
   分页，并定位当前题。

## 需求维护规则

- 本目录是需求唯一维护位置；根 `README.md` 只保留产品概览和本目录入口。
- 页面内行为写入对应分页文件；跨页面、数据、范围和非目标写入本总览。
- 新增或修改行为时保留稳定需求编号，并同步更新自动化测试和必要的响应式浏览器验收。
- 已确认取消或替代的设计不得继续作为并列方案保留在需求中。

## 明确不做

- 随机换题或随机跳题。
- 独立的数字/候选模式切换。
- 独立的清除所选单元格按钮。
- 账号、云端同步、排行榜、积分、广告和社交功能。

“随机跳转到一道题”可在后续版本评估，不属于当前验收范围。

- `./scripts/test` 通过。
- 桌面和手机尺寸完成浏览器验收。
- 文档描述与当前实现一致，`git diff --check` 无错误。

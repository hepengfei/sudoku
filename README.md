# Sudoku

一个数独项目，目标是实现清晰、可靠且易于扩展的数独游戏与核心能力，包括棋盘校验、候选数计算、求解以及题目生成。

## 当前状态

项目目前处于初始化阶段，尚未确定具体技术栈，也还没有可运行的程序。首个实现应把数独领域逻辑与界面、存储等外部能力分离，并提供统一的自动化入口：

```text
./scripts/setup
./scripts/check
./scripts/test
```

这些脚本会随首个功能实现一并加入。详细的工程约束、测试要求和 Agent 协作规范见 [AGENTS.md](./AGENTS.md)。

## 基本规则

默认采用标准 9×9 数独：

- 每个单元格为空或填写 1–9；
- 每一行、每一列和每个 3×3 宫内的数字不能重复；
- 题目给定数字在游戏过程中不可修改；
- 生成的标准题目需要保证解唯一。

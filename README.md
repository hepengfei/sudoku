# Sudoku

一个数独项目，目标是实现清晰、可靠且易于扩展的数独游戏与核心能力，包括棋盘校验、候选数计算、求解以及题目生成。

## 当前状态

第一版是一个响应式 Web 数独本，可在桌面、iPad 和手机浏览器中使用。它不需要账号或网络服务，游戏进度和完成历史只保存在当前浏览器的 `localStorage` 中。

当前功能：

- 通过首页题库翻阅简单、中等、困难、地狱四个难度的全部题目，每档 1000 题；
- 查看各难度的总题数、开始/完成进度，以及每题状态和本地挑战记录；
- 棋盘底部固定显示一排 1–9 数字键：短按切换候选数字，长按填写确定数字；
- 长按不同数字会替换当前确定数字，长按相同数字会取消该确定数字；
- “清空重做”会清除当前题的全部填写和候选，并重置本次用时及判错次数，不影响历史最佳记录；
- 游戏页第一行集中显示应用名称与清空、提交、返回题库菜单，第二行集中显示题号、用时、判错、挑战次数和最佳用时；
- 给定数字不可修改，不提供提示或即时冲突校验；
- 主动提交时只告知整体正确或不正确，不标出错位；
- 自动保存当前进度，并记录用时、提交判错次数和最近 100 次完成历史。

项目采用原生 HTML、CSS 和 JavaScript ES Modules，领域规则、游戏状态、浏览器存储与界面彼此分离，没有第三方运行时依赖。

### 输入交互验收契约

- 页面不提供数字/候选模式切换，也不提供清除单元格按钮；
- 数字区始终是一排 1–9 数字键；
- 短按数字键只切换候选：不存在时加入，已存在时取消；
- 长按数字键只切换确定数字：不同数字会填写或替换，相同数字会取消；每次长按都会清除该格候选；
- 鼠标和触控统一使用指针事件，长按触发后不得再触发同一次按压的短按操作。
- 数字键区域在 iOS Safari 上不得触发文字选择、系统长按菜单、拖拽或触控高亮，同时保留按钮语义与键盘短按能力。
- 候选数字固定排列为等高的 3×3 网格，不得因只有两排或填写第三排而改变位置或单元格尺寸。

### 题库验收契约

- 目录按简单、中等、困难、地狱分为四个标签页，明确展示总题数、已开始、已完成、未完成及“完成 N / 总数”；
- 每页显示 50 题，分页条固定悬浮在页面底部；从游戏返回题库时自动回到当前题所在分页并定位该题；
- 目录卡片保持紧凑，目录页和游戏页到达实际内容底部后不再产生额外空白滚动；
- 每题只展示真实的本地状态和统计：未开始、进行中或已完成，正确挑战次数、最短完成用时及该记录的完成日期时间；没有完成记录时以 `—` 显示；
- 进行中题目从目录进入时恢复各自上次保存的棋盘、候选、用时和判错次数；
- 已完成题目可以再次挑战；每次正确完成累积一次挑战次数，只有更短时才替换最佳用时和对应日期时间；
- v1 的单题进度与完成历史会在本地一次性迁移，目录和逐题进度仍只使用当前浏览器存储；
- 不加入随机换题、排行榜、积分、账号、云端同步或即时提示。

后续可评估增加“随机跳转到一道题”，本版不实现。

### 题库来源

内置 4000 道题来自公有领域的
[Sudoku Exchange Puzzle Bank](https://github.com/grantm/sudoku-exchange-puzzle-bank)，
按 Easy、Medium、Hard、Diabolical 四档使用固定随机种子各抽取 1000 题。导入时由
本项目求解器重新验证唯一解并生成答案。完整来源、上游版本、文件校验和、抽样种子
和复现命令见
[`docs/knowledge/sudoku-exchange-import.md`](docs/knowledge/sudoku-exchange-import.md)。
四档题目分别存放为静态模块，页面按当前难度延迟加载，浏览器会缓存已经打开过的
题库文件。

## 开发

需要 Node.js 20 或更高版本。仓库提供统一的自动化入口：

```text
./scripts/setup
./scripts/check
./scripts/test
```

本地启动：

```sh
npm run dev
```

然后访问终端输出的地址（默认 `http://127.0.0.1:4173`）。如需让同一局域网中的设备访问，可运行：

```sh
HOST=0.0.0.0 npm run dev
```

详细的工程约束、测试要求和 Agent 协作规范见 [AGENTS.md](./AGENTS.md)。

## 基本规则

默认采用标准 9×9 数独：

- 每个单元格为空或填写 1–9；
- 每一行、每一列和每个 3×3 宫内的数字不能重复；
- 题目给定数字在游戏过程中不可修改；
- 生成的标准题目需要保证解唯一。

# 开放数独题库调研

## 文档信息

- 调研日期：2026-07-26
- 调研范围：可用于标准 9×9 数独应用的公开题库
- 关注点：授权是否明确、能否再分发及商用、题目规模、难度信息、唯一解和接入成本
- 结论状态：可作为题库选型依据；正式导入仍需执行本文的验收步骤

## 结论

项目内置题库首选
[Sudoku Exchange Puzzle Bank](https://github.com/grantm/sudoku-exchange-puzzle-bank)。
它的来源、生成方式、唯一解保证、难度划分和公有领域声明都比较清晰，
比仅由第三方上传者在数据平台上声明 CC0 的大规模数据集更容易追溯。

不建议直接抓取报纸、杂志、纽约时报、Nikoli、商业 App 或普通数独网站的题目。
公开可访问或免费下载不代表允许复制、打包、再分发或商用。

严格来说，“开源”通常用于软件代码，题库更适合称为“开放数据”或
“公有领域数据”。不同司法辖区对权利放弃的认定可能不同，因此项目仍应保留
题库来源、许可证文本和取得日期。本文不是法律意见。

## 候选题库

### 1. Sudoku Exchange Puzzle Bank

- 地址：
  [GitHub 仓库](https://github.com/grantm/sudoku-exchange-puzzle-bank)
- 规模：数十万道程序生成题目。
- 内容：题目、稳定哈希和 Sukaku Explainer 难度评分。
- 难度：Easy、Medium、Hard、Diabolical 四档。
- 唯一解：仓库说明题目由 QQWing 生成，并保证每题有唯一解。
- 格式：每行三个空格分隔字段，依次为 12 字节哈希、81 位题目字符串和评分；
  空格用 `0` 表示。
- 授权：数据集投入公有领域，仓库附带
  [LICENSE.txt](https://github.com/grantm/sudoku-exchange-puzzle-bank/blob/master/LICENSE.txt)。
  许可证明确允许复制、修改、发布、使用、编译、销售和分发，包括商业用途。
- 补充证据：
  [Sudoku Exchange 官方题库说明](https://sudokuexchange.com/puzzle-bank/)
  明确表示题目不受版权限制，可为任何目的使用和分享。

评价：最适合作为本项目的产品题库。授权链清晰、无需自行建立难度体系，并且
可以按难度只导入需要的子集。

### 2. 9 Million Sudoku Puzzles and Solutions

- 地址：
  [Kaggle 数据集](https://www.kaggle.com/datasets/rohanrao/sudoku/data)
- 规模：900 万道，CSV 约 1.48 GB。
- 内容：每行包含题目和答案，空格用 `0` 表示。
- 授权：数据页面标注 CC0 Public Domain。
- 难度：没有适合产品直接使用的难度分档。

评价：适合求解器压力测试、抽样和数据分析，不建议完整打包进客户端。许可证由
Kaggle 上传者声明，正式使用前应保存数据页面和许可证快照，并核实上传者对全部
内容有权作出 CC0 声明。

### 3. 3 Million Sudoku Puzzles with Ratings

- 地址：
  [Kaggle 数据集](https://www.kaggle.com/datasets/radcliffe/3-million-sudoku-puzzles-with-ratings)
- 规模：300 万道。
- 内容：题目、答案和难度评分。
- 授权：数据页面标注 CC0 Public Domain。

评价：适合难度算法研究或作为补充数据源。与其他 Kaggle 数据集一样，使用前应
额外核实数据来源和上传者的授权能力。

### 4. 1 Million Sudoku Games

- 地址：
  [Kaggle 数据集](https://www.kaggle.com/datasets/bryanpark/sudoku)
- 规模：100 万道。
- 内容：题目和答案。
- 授权：数据页面标注 CC0 Public Domain。

评价：格式简单，适合测试或抽样，但缺少产品可直接使用的难度信息，来源追溯性
弱于 Sudoku Exchange。

### 5. Project Pluto psudoku

- 地址：
  [示例题集 PDF](https://www.projectpluto.com/psudoku/examp6.pdf)
- 内容：由 `psudoku` 生成的题目，同时提供生成程序。
- 授权：题集内明确声明生成的题目属于公有领域，可以任意使用，并建议注明来源。

评价：授权说明直接，但现成题库的分发格式不如前述文本或 CSV 数据集方便。更
适合作为备用生成来源或交叉验证来源。

### 6. Sudoku Image Dataset

- 地址：
  [GitHub 仓库](https://github.com/wichtounet/sudoku_dataset)
- 规模：约 200 张数独照片和相应棋盘数据。
- 授权：数据和图片为 CC BY 4.0，代码为 MIT。
- 要求：使用数据或图片时需要按 CC BY 4.0 署名。

评价：适合数独图像识别和 OCR，不适合作为当前游戏的主题库。它不是“无版权”
数据。

## 许可证判断

[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
表示权利人在法律允许的最大范围内将作品贡献给公有领域。它允许无需另行申请
许可地复制、修改、分发、表演以及商业使用。

应区分以下情况：

- 公有领域或 CC0：通常可以直接复制、修改、再分发和商用；
- CC BY：可以商用和修改，但必须满足署名等条件；
- MIT、GPL、AGPL 等软件许可证：需要确认许可证覆盖的是生成程序、应用代码，
  还是同时明确覆盖生成出来的题目数据；
- 没有许可证：不能因为仓库公开或文件可以下载就推定允许再分发；
- 网站自行展示的题目：网站条款、单题权利和数据库集合权利需要分别判断。

## 对本项目的推荐接入方案

1. 从 Sudoku Exchange 每个目标难度选择一个受控子集，不把全部题库直接打包到
   Web 客户端。
2. 将上游 `LICENSE.txt`、来源 URL、上游提交版本或下载日期随导入数据一起保存。
3. 保留原始 81 位题目字符串和上游评分；内部稳定 ID 可由来源前缀、难度和原始
   哈希组成。
4. 当前项目题目使用 `.` 表示空格，而上游使用 `0`。导入阶段应显式转换，
   不能让两种格式渗透到领域层。
5. 不直接信任上游答案或唯一解声明。导入工具应使用本项目求解器重新求解并
   验证唯一解，再生成项目使用的答案。
6. 产品难度映射为五档：Easy 中给定数不少于 40 的题目→入门、其余 Easy→简单、
   Medium→中等、Hard→困难、Diabolical→地狱，不合并 Hard 和 Diabolical。
7. 题库导入结果应是可重复生成的固定数据，不应在构建或测试时访问网络。

## 导入验收清单

每道导入题目至少应通过以下检查：

- 恰好包含 81 个单元格；
- 每个单元格只包含 `1`–`9` 或空格标记；
- 给定数字没有行、列或 3×3 宫冲突；
- 至少存在一个解；
- 解唯一；
- 保存的完整答案通过标准数独校验；
- 题目 ID 在本地题库中唯一；
- 重复题目能够按标准化后的 81 位字符串去重；
- 难度值和难度映射可追溯；
- 固定输入在重复导入时产生完全相同的输出。

## 证据保全建议

正式导入时，建议在题库数据旁保存一份来源清单，至少包括：

- 数据集名称和原始 URL；
- 下载日期；
- 上游提交哈希、版本号或文件校验和；
- 原始许可证文件；
- 实际导入的记录数；
- 筛除的无效、非唯一解和重复记录数；
- 使用的难度映射规则；
- 导入工具版本或仓库提交哈希。

这样可以在上游网页、仓库或许可证发生变化后，仍然回答项目内每道题的来源和
使用依据。
